# Obtenir de l'aide

🇬🇧 [English version](./SUPPORT.en.md)

QcWeather est un projet personnel, maintenu par une seule personne sur son temps libre : il n'y a pas de support commercial ni de garantie de délai de réponse.

## Avant de demander de l'aide

1. Vérifier [TROUBLESHOOTING.md](./TROUBLESHOOTING.md) — les cas déjà rencontrés (config nginx, calibrage réseau, CI, dérive de contrat des APIs externes) y sont documentés avec la démarche de diagnostic suivie.
2. Vérifier [`GET /api/sante`](https://qcweather.alithiel31.dev/api/sante) — confirme si le backend répond avant de signaler une panne.
3. Chercher dans les [issues existantes](https://github.com/Alithiel31/WeatherQC/issues), ouvertes et fermées.

## Signaler un bug ou demander une fonctionnalité

Ouvrir une [issue](https://github.com/Alithiel31/WeatherQC/issues/new/choose) — les gabarits demandent le contexte utile (ville concernée, endpoint, `X-Request-Id`...).

## Contribuer

Environnement de développement, reproduction de la CI en local, convention de commit : voir [CONTRIBUTING.md](./CONTRIBUTING.md).

## Signaler une vulnérabilité de sécurité

**Ne pas** utiliser ce canal pour une faille de sécurité — voir [SECURITY.md](./SECURITY.md), qui décrit le signalement privé via GitHub Security Advisories.
