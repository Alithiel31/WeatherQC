# Getting Help

🇫🇷 [Version française](./SUPPORT.md) — this is the canonical version of this document.

QcWeather is a personal project, maintained by a single person in their spare time: there is no commercial support and no response-time guarantee.

## Before asking for help

1. Check [TROUBLESHOOTING.md](./TROUBLESHOOTING.md) — cases already encountered (nginx config, network tuning, CI, external API contract drift) are documented there, along with the diagnostic steps that were followed.
2. Check [`GET /api/sante`](https://qcweather.alithiel31.dev/api/sante) — confirms whether the backend is responding before you report an outage.
3. Search the [existing issues](https://github.com/Alithiel31/WeatherQC/issues), open and closed.

## Reporting a bug or requesting a feature

Open an [issue](https://github.com/Alithiel31/WeatherQC/issues/new/choose) — the templates ask for the useful context (affected city, endpoint, `X-Request-Id`...).

## Contributing

Development environment, reproducing CI locally, commit conventions: see [CONTRIBUTING.md](./CONTRIBUTING.md).

## Reporting a security vulnerability

**Do not** use this channel for a security flaw — see [SECURITY.md](./SECURITY.md), which describes private reporting via GitHub Security Advisories.
